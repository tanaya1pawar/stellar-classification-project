# Stellar Classification Project

## 👤 Author

## 🌟 Project Overview
This project focuses on the classification of celestial objects (such as stars, galaxies, and quasars) utilizing machine learning algorithms and astronomical data (specifically spectral data features). The goal is to accurately categorize these objects based on their photometric and spectroscopic properties.
